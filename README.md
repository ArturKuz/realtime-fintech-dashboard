# Realtime Fintech Dashboard

An Angular application with a live market dashboard and producer settings. Simulated market data is
generated by a WebAssembly module (AssemblyScript) running inside a Web Worker.

> Work in progress. Architecture, decisions and the live demo link will be documented here as the
> project grows.

## Prerequisites

- **Node.js 24 LTS** (`24.22.1`, see `.nvmrc`). Angular CLI 22 needs `^24.15.0` or `>=26`.
- **pnpm 12** through Corepack (the exact version is pinned in `package.json` → `packageManager`):

  ```bash
  corepack enable pnpm
  ```

## Getting started

```bash
pnpm install
pnpm start          # dev server on http://localhost:4200
```

## Scripts

| Script              | What it does                                    |
| ------------------- | ----------------------------------------------- |
| `pnpm start`        | Run the dev server with live reload             |
| `pnpm build`        | Production build into `dist/`                   |
| `pnpm build:pages`  | Production build for GitHub Pages (see below)   |
| `pnpm test`         | Run all unit tests once (Vitest)                |
| `pnpm test:watch`   | Run unit tests in watch mode                    |
| `pnpm lint`         | ESLint (TypeScript with type information, HTML) |
| `pnpm format`       | Format all files with Prettier                  |
| `pnpm format:check` | Check formatting without writing                |

## Deployment

Every push runs [GitHub Actions](.github/workflows/ci.yml): install → lint → format check → tests →
production build. A green build of `main` is then deployed to GitHub Pages automatically; other
branches and pull requests only run the checks, so a broken change never reaches the live demo.

Live demo: _link added after the first deployment_.

Two GitHub Pages details are handled by `pnpm build:pages`:

- The site lives under `/realtime-fintech-dashboard/`, so the app is built with that `--base-href`.
- Pages does not know Angular routes, so reloading `/settings` would return 404.
  `scripts/copy-404.mjs` copies `index.html` to `404.html`; Pages serves it for unknown paths, the
  app boots and the router shows the right page.

## Tooling

- **Angular 22**: standalone components, zoneless change detection, signals.
- **TypeScript 6.0**, strict mode (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, strict
  templates). TypeScript 7 is not yet supported by Angular 22.
- **Vitest** through the Angular CLI `unit-test` builder (jsdom).
- **ESLint** flat config with angular-eslint and type-aware typescript-eslint rules; **Prettier**
  formats, ESLint checks logic (`eslint-config-prettier` turns off the overlapping rules).
- **Husky + lint-staged** lint and format staged files before each commit; **commitlint** enforces
  [Conventional Commits](https://www.conventionalcommits.org/).
